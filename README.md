# Star Citizen Strings Replacements
---
### Description:

- Contracts that award blueprints have the potential pool added to the end of the description
- Contracts that award BP's have `[BP]` in the title
- Contracts that award XP's have `[XX XP]` in the title
  - Eg. `Salvager Needed (Lrg. Special Order of RMC / UCM / Components) [BP] [150 XP]`
- Warning prefixes for illegal substances
- Componenet Type/Size/Grade prefixed to the name in style `[TSG] Name`
  - Eg. `FR-66` -> `[M1A] FR-66`
- Mark all materials used for crafting by `©`
- `Hephaestanite (Raw)` shortened to `Heph (Raw) ©`
- Hauling contract titles cleaned up and Direct underlined
- `Instability:/Resistance:` shortened to `Instab.:/Resist.:` due to overlapping issues
- Reformatted the Mining guide journal entry to group ores by rarity (CIG not updated it since 4.6)
- Added Type notation prefix for missiles
  - Eg. `Dominator II Missile` -> `[EM1] Dominator II Missile`

### Installation

1. Download structure from Mods
2. Copy all to you Star Citizen Live game folder
